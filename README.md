# 凪野町（なぎのちょう）— AIだけの街

架空の港町に住人8人が暮らし、働き、話し、噂し、3日目の夕方の町民集会で投票するまでを、ブラウザで見下ろして眺めるローカルアプリです。住人の一人ひとりを Claude が演じます。人間はふだん眺めるだけで、ときどき「天の声」として出来事を投げ込みます。

- 住人に返させるのは「次に何をするか」を書いた JSON だけです（structured outputs）。tool use・コード実行・Web 検索・ファイル操作は渡しません。
- 物の数、売り買い、受け渡し、投票の集計はプログラムが判定します。AI が「買った」と言っても、在庫やお金が足りなければ失敗します。
- サーバーは 127.0.0.1 にだけバインドします。外への通信は Anthropic の API だけです（画面のフォント読み込みを除く）。

## 動かし方

Node.js 20.12 以上が必要です。

```bash
npm install
npm start
```

ブラウザで http://127.0.0.1:8787 を開き、「再生」を押します。既定は mock（API を呼ばない偽物の住人、費用 $0）です。

### 本物の住人（real）で動かす

1. Claude Console でこの町専用のワークスペースと API キーを用意し、ワークスペースに支出の上限を設定します。
2. `.env.example` を `.env` という名前でコピーし、`TOWN_ANTHROPIC_API_KEY=` の後ろにキーを書き、`LLM_MODE=real` にします。キーは `ANTHROPIC_API_KEY` ではなく、この専用の名前で書きます。
3. `npm start` で起動すると、画面左上の表示が REAL になります。

キーは画面にもログにも出しません。キーが無いときは mock で起動し、その旨を画面に出します。

### 動作確認だけをする

```bash
npm run probe
```

送らずに、1回の呼び出しの大きさと最悪の費用を表示します。`npm run probe -- --yes` で、本番と同じ形の呼び出しを1回だけ送ります。

## 費用の上限

`config/budget.json` で決めます。既定は1回の実行（run）あたり $3、全 run の累計（`../ledger/ledger.jsonl`）で $90 です。どちらかに達すると、その場で止まります。呼び出しの前にも「最悪の費用を足して上限を超えないか」を確かめます。ブラウザが30秒つながっていないとき、1日が終わったときにも自動で止まります。

## 画面

- 上のバー：日付と時刻、再生／一時停止／1ティック／速度（1倍・4倍）、費用、天の声、内心の表示、書き出し、過去の記録の再生
- 地図：住人をクリックすると人物カード（所持金・空腹度・予定・気分・関係値・最近の記憶・思い込み）が出ます
- 右側：ログ。人物で絞り込めます
- 1日の終わりに町の新聞『凪野町報』が出ます

## 設定

| ファイル | 中身 |
|---|---|
| `config/characters.json` | 住人（口調・目的・秘密・所持金・記憶の上限・初めの関係値） |
| `config/world.json` | 時間、場所、パン屋、空腹、時給、集会、出来事、記憶の選び方 |
| `config/models.json` | 役割ごとのモデル・effort・thinking。住人ごとの上書き |
| `config/pricing.json` | 料金表（100万トークンあたり USD） |
| `config/budget.json` | 費用の上限など |

モデルと thinking の組み合わせは起動時に検査し、API が受け付けない組み合わせなら起動しません。

## 記録

1回の実行ごとに `../runs/（YYYYMMDD-HHMMSS）/` を作り、次を残します。

- `events.jsonl`：すべての出来事、全住人の行動・発言・内心
- `llm_calls.jsonl`：呼び出しごとのモデル・トークン数・費用・所要時間・検証の成否・プロンプト全文と返答
- `cost.jsonl`：費用の累計
- `config/`：その回の設定
- `newspaper_day1_v1.md` など：新聞、`log_v1.md`：ログ、`map_*.png`：地図

「過去の記録を再生」で、API を呼ばずに何度でも見直せます。

## そのほかのコマンド

```bash
npm run headless   # 画面なしで mock の3日間を最後まで走らせる
npm run selfcheck  # ブラウザ側が標準 API だけで書けているか、安全上の約束を守っているかを点検する
```
